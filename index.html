👋 Première utilisation — Configuration requise
Pour que vos saisies soient enregistrées dans Google Sheets, suivez ces étapes :
  1. Dans Apps Script Editor → exécutez creerSheetAutomatiquement() (ou lierSheetExistant() si vous avez déjà un Sheet)
  2. Déployez le script : Déployer → Nouvelle déploiement → Application Web (Accès : Tout le monde)
  3. Copiez l'URL → collez-la ici dans ⚙️ Configuration → Synchronisation (mot de passe : admin2025)
